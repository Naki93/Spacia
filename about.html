ABOUT PROJECT

This project started as a small experiment to combine coding and design. I wanted to practice DOM manipulation using input sliders — getting and setting values dynamically — while also exploring typography, visual hierarchy, and UX/UI principles like proximity, alignment, padding, and margin.
By adjusting the sliders, I could see in real time how spacing affects layout, which helped me connect design theory with practical code.

I PRACTICED

DOM Manipulation – selecting elements, updating values, and dynamically styling elements with JavaScript.
CSS Layout & Styling – working with padding, margin, and responsive design.
UX/UI Principles – understanding alignment, spacing, and visual hierarchy.
