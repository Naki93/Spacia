# Visual Spacing Guide

I built this project while learning about **DOM manipulation** in JavaScript.  
I wanted to practice **getting values from input boxes** and **styling elements dynamically**, so I decided to create a simple app that demonstrates how **padding** and **margin** affect layout.

Since I'm also into design, this was a fun way to combine both learning and creativity.

### Features

- Interactive sliders for padding and margin
- Real-time updates to the box’s spacing
- A visual guide for how layout changes

### Challenges

One of the main challenges I faced was making it **mobile responsive**.  
At first, increasing the margin caused overflow issues on smaller screens, but I learned how to fix that with media queries and better sizing.

### How to Use

1. Open the app in your browser.
2. Drag the **padding** and **margin** sliders to see how spacing changes.
3. Try it on desktop and mobile for a responsive experience.

This project helped me understand the **DOM, input handling, and dynamic styling in JavaScript**, and also gave me some hands-on practice with responsive design.
